# 一键切换搜索引擎 — 使用手册

## 功能概述

当对当前搜索结果不满意时，可一键切换到其他搜索引擎获取更多结果URL。

## 支持的引擎

| 引擎 | 触发词 |
|------|--------|
| Google 谷歌 | `google` / `谷歌` |
| Bing 必应 | `bing` / `必应` |
| Baidu 百度 | `baidu` / `百度` |

## 使用方式

### 示例1：对搜索结果不满意，换引擎
```
User: 换必应搜一下"量子计算最新进展"
Agent: [返回Bing搜索结果URL列表]
```

### 示例2：拓宽搜索范围
```
User: 刚才的结果不够全面，用谷歌再搜一次
Agent: [返回Google搜索结果]
```

### 示例3：指定多引擎
```
User: 分别用谷歌和百度搜索"AI芯片市场报告"
Agent: [依次返回两个引擎的结果]
```

## 返回值格式

每次搜索返回结构化结果，包含：标题、URL链接、摘要描述。

## 文件说明

- `SKILL.md` — 技能定义文件（位于 `0_system/skills/search-engine-switcher/`）
- `skills.csv` — 技能注册表（位于 `0_system/skills/`）
- 执行时自动调用 `web_search` 工具，无需手动配置
