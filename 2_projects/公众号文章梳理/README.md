# 公众号文章梳理

## 触发方式

| 说这句话 | 做什么 |
|----------|--------|
| **贴一篇微信文章链接** | 扒文章 → 保存到 `2_已学习文章/` |
| **"整理学习内容"** | 读取 `3_学习输出/学习.txt` → 扒文章 + 生成待审阅 + 更新标的 |

## 关键文件

| 文件 | 用途 |
|------|------|
| `3_学习输出/学习.txt` | 你的笔记（链接 + 感悟 + 标的），不改它 |
| `context.md` | 完整规则（AI 看） |
| `README.md` | 快速入口（你看着我说） |
