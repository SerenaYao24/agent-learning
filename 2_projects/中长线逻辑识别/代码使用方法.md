# 脚本速查

## 每日一键流程（最常用）

```bash
# 仅分析+看板（日常最常用）
python3 2_projects/中长线逻辑识别/daily_run.py --analyze

# 全流程（含涨停板复盘提醒）
python3 2_projects/中长线逻辑识别/daily_run.py
```

按顺序自动执行：自选股趋势分析 → 题材筛选 → MA5 角度排名 → 成交额排行 → 指数+ETF 数据 → 异常检测 → 生成看板 → 重启看板服务 → 打开浏览器。
任一步失败不中断，继续跑后续步骤，最后汇总成功/失败数。
涨停板复盘需人工确认（股票归类），走 `/limit-up-review` skill 单独触发。

## 在用脚本

### `scrape_ma5_ranking.py` — 全市场 MA5 角度排行（爬虫）

```bash
# 默认 Top 200，非 ST
python3 2_projects/中长线逻辑识别/scrape_ma5_ranking.py

# 只显示前 30
python3 2_projects/中长线逻辑识别/scrape_ma5_ranking.py --top 30

# JSON 输出，不存文件
python3 2_projects/中长线逻辑识别/scrape_ma5_ranking.py --json --no-save
```

### `stock_trend_analysis.py` — 自选股趋势分析 + 出报告

```bash
# 日常增量
python3 2_projects/中长线逻辑识别/stock_trend_analysis.py -i 2_projects/中长线逻辑识别/interest_stock.md

# 全量刷新 API
python3 2_projects/中长线逻辑识别/stock_trend_analysis.py -i 2_projects/中长线逻辑识别/interest_stock.md --refresh

# 仅多日汇总
python3 2_projects/中长线逻辑识别/stock_trend_analysis.py -i 2_projects/中长线逻辑识别/interest_stock.md --multi

# 仅用缓存重生成报告
python3 2_projects/中长线逻辑识别/stock_trend_analysis.py -i 2_projects/中长线逻辑识别/interest_stock.md --force-gen
```

| 参数 | 说明 |
|------|------|
| `-i` | 标的列表文件（必填） |
| `--refresh` | 忽略缓存，全量拉取 |
| `--multi` | 跳过单日报告，仅多日汇总 |
| `--force-gen` | 不调 API，仅用缓存重新生成报告 |
| `-o` | 指定输出文件路径 |

### `stock_filter.py` — 多日报告题材/标的筛选

```bash
# 基于最新多日报告（交互模式）
python3 2_projects/中长线逻辑识别/stock_filter.py

# 指定日期
python3 2_projects/中长线逻辑识别/stock_filter.py --date 05-14

# 非交互模式（批量运行所有筛选器）
python3 2_projects/中长线逻辑识别/stock_filter.py --all --save-tags
```

### `generate_trend_page.py` — K 线 + 成交额走势 HTML

```bash
# 默认 20 日
python3 2_projects/中长线逻辑识别/generate_trend_page.py

# 题材模式
python3 2_projects/中长线逻辑识别/generate_trend_page.py --sector 光通信

# 指定文件 + 天数
python3 2_projects/中长线逻辑识别/generate_trend_page.py -i 2_projects/中长线逻辑识别/interest_stock.md --days 30
```

| 参数 | 说明 |
|------|------|
| `-i` | 标的文件（默认 interest_stock.md） |
| `--sector` | 题材名，从 interest_stock.md 中找该题材标的 |
| `--days` | 近 N 个交易日（默认 20） |
| `-o` | 输出 HTML 路径 |

### `generate_dashboard.py` — 数据看板 HTML

```bash
# 生成静态看板页面
python3 2_projects/中长线逻辑识别/generate_dashboard.py
```

纯静态 HTML（ECharts），6 个 Tab：指数宏观 / ETF宏观 / 板块数据 / 个股数据 / 大宗交易 / 重点监控。
指标栏（涨跌家数/成交额/风险标签）全局可见。风险标签支持手动添加/删除，持久化到 localStorage。
指数3图 + ETF3图，ETF Tab 惰性渲染。上证量能柱用 (上证+深证) * 1.01。
大宗交易 Tab：近5日数据树状表格（按题材分组），折溢率×100%显示，支持展开/折叠，固定列宽。
重点监控 Tab：手动录入股票监管信息，类型可选（重点监控/触发严重异动），开始/结束日期联动，过期灰色显示。

### `stock_trend_analysis.py` — 自动生成 top_list（内嵌）

数据获取完成后自动调用内嵌的 `generate_top_list()` 更新 `top_list.md`，无需单独执行。
top_list 用于题材统计（排除僵尸股）和 dashboard 个股展示。

### `index_data.py` — 大盘指数 + ETF 日线 + 分时数据

```bash
# 默认：指数 m1 + ETF m5，含分钟线 + 上涨下跌家数
python3 2_projects/中长线逻辑识别/index_data.py

# 跳过分钟线
python3 2_projects/中长线逻辑识别/index_data.py --no-minute

# 跳过 ETF
python3 2_projects/中长线逻辑识别/index_data.py --no-etf

# 重建全部指数日线历史（90 天，格式统一）
python3 2_projects/中长线逻辑识别/index_data.py --backfill --no-minute --no-etf
```

覆盖：上证/深证/创业板/科创综指 + 6 只 ETF。
指数分钟线 m1（交易日当天完整），ETF 分钟线 m5。市场宽度从短线侠 qxlive 获取（Playwright）。总成交额 = (上证+深证) * 1.01。

## daily_run 数据流全景

`daily_run.py --analyze` 按顺序执行 7 步，每步产出文件供后续步骤或 `dashboard.html` 消费。

### 步骤产出速查

| # | 步骤 | 产出文件 | 给谁用 |
|---|------|----------|--------|
| ① | 趋势分析 | `.stock_cache/stock_data.json`<br>`.stock_cache/reports/每日分析/*.md`<br>`.stock_cache/reports/多日分析/*.md`<br>`.stock_cache/parse_cache/*.json` | ② ③ ⑦ |
| ② | 题材筛选 | `.index_data/filter_tags.json` | ⑦ |
| ③ | MA5 排行 | `.ma5_ranking/ranking_{date}.csv` | ⑦ |
| ④ | 成交额排行 | `.ma5_ranking/amount_ranking_{date}.csv` | ⑦ |
| ⑤ | 指数+ETF | `.index_data/index_daily_{date}.csv`<br>`.index_data/etf_daily_{date}.csv`<br>`.index_data/*_minute_*.csv`<br>`.index_data/breadth_{date}.csv` | ⑥ ⑦ |
| ⑥ | 异常检测 | `risk_tags.json`、`opp_tags.json` | ⑦ + dashboard API |
| ⑦ | 生成看板 | `dashboard.html` | 浏览器 |

### 各步骤产出文件详情

#### ① `stock_trend_analysis.py`（自选股趋势分析）

| 产出文件 | 数据结构 |
|----------|----------|
| `.stock_cache/stock_data.json` | `{股票代码: {dates, daily_changes, open, close, high, low, amount}}` — 全量 OHLCV 缓存 |
| `.stock_cache/stock_code_map.json` | `{股票名称: 股票代码}` |
| `.stock_cache/reports/每日分析/stock_trend_report_{date}.md` | 题材分析表 + 评级统计 |
| `.stock_cache/reports/每日分析/stock_trend_report_{date}_detail.md` | 标的汇总表 + 窗口1~6 涨跌幅 + 结论(⭐/🟢/🟡/🔴) |
| `.stock_cache/reports/多日分析/multi_day_trend_{date}.md` | 多日汇总：题材情况表(d1~d5) + 板块强弱 |
| `.stock_cache/reports/多日分析/multi_day_trend_{date}_detail.md` | 全部标的详情 |
| `.stock_cache/parse_cache/stock_trend_report_{date}.json` | 结构化缓存（窗口数据、结论） |

> 同时写入 iCloud：`~/Library/Mobile Documents/.../股票分析结果/`

#### ② `stock_filter.py --all --save-tags`（题材筛选）

| 产出文件 | 数据结构 |
|----------|----------|
| `.index_data/filter_tags.json` | `{"抗跌题材": ["题材A", "题材B"], "加强题材": ["题材C"]}` |

两个筛选器：
- **抗跌题材**：d4 > 0 且 (d5 > 0 或 |d5| < d4/2)
- **加强题材**：d4 > 0 且 d5 > 0 且 d5 > d4 且 d5 > 3%

#### ③ `scrape_ma5_ranking.py`（MA5 角度排行）

| 产出文件 | 数据结构 |
|----------|----------|
| `.ma5_ranking/ranking_{date}.csv` | `排名, 代码, 名称, 角度, 最新价, 涨跌幅 [, MA5, 换手率, 成交量, 成交额]`（200条） |

> 数据来源：东方财富条件选股（Playwright 爬虫）

#### ④ `scrape_amount_ranking.py`（成交额排行）

| 产出文件 | 数据结构 |
|----------|----------|
| `.ma5_ranking/amount_ranking_{date}.csv` | `排名, 代码, 名称, 最新价, 涨跌幅, 成交额 [, 换手率, 成交量]`（50条） |

#### ⑤ `index_data.py`（指数+ETF 数据）

| 产出文件 | 数据结构 |
|----------|----------|
| `.index_data/index_daily_{date}.csv` | 上证/深证/创业板/科创综指 OHLCV + 成交额 |
| `.index_data/etf_daily_{date}.csv` | 6只ETF OHLCV + 成交额 |
| `.index_data/index_minute_{指数}_{date}.csv` | `time, open, price, volume, amount`（m1 分钟线） |
| `.index_data/index_minute_m5_{指数}_{date}.csv` | 同上（m5，多日历史） |
| `.index_data/etf_minute_{ETF}_{date}.csv` | ETF m5 分钟线 |
| `.index_data/breadth_{date}.csv` | `上涨家数, 下跌家数, 涨停家数, 跌停家数` |

> 数据源：Sina（指数日线）、腾讯 mkline（分钟线）、短线侠 qxlive（市场宽度）

#### ⑥ `anomaly_detection.py --save-tags`（异常检测）

| 产出文件 | 数据结构 |
|----------|----------|
| `risk_tags.json` | `{"manual": ["0527: ETF量能异常...", ...], "deleted": ["普涨"]}` |
| `opp_tags.json` | `{"manual": ["0527: 二冰...", ...], "deleted": []}` |

4个策略：ETF异动、指数量能异动、指数震荡区间、赚钱效应（冰点/放量下跌）

#### ⑦ `generate_dashboard.py`（生成看板）

| 产出文件 | 说明 |
|----------|------|
| `dashboard.html` | 自包含单文件 HTML，所有图表数据内嵌为 JS 变量 |

内嵌数据变量：
- `STOCK_MAP` — 个股 OHLCV + 涨跌幅（来源①）
- `index_json` — 指数日K + 分时数据（来源⑤）
- `etf_json` — ETF 日K + 分时数据（来源⑤）
- `rank_json` — MA5 排行 Top30（来源③）
- `block_json` — 大宗交易数据（来源 akshare API）
- `sector_json` / `theme_order_json` / `theme_avg_json` — 板块数据（来源①）
- `filter_tags_json` — 筛选标签（来源②）
- `monitor_json` — 重点监控（来源 `monitor.json`）

### dashboard 前后端数据流

```
dashboard.html（浏览器）
  │
  │  页面加载时（静态数据，内嵌在 HTML 中）:
  │  ├─ STOCK_MAP, index_json, etf_json, rank_json      ← 不通过 API，直接可用
  │  ├─ block_json, sector_json, filter_tags_json        ← 同上
  │  └─ monitor_json                                     ← 同上
  │
  │  页面加载时（动态 fetch）:
  │  ├─ GET /api/risk-tags   → risk_tags.json            ← dashboard_server.py
  │  ├─ GET /api/opp-tags    → opp_tags.json             ← dashboard_server.py
  │  └─ GET /api/index-state → index_state.json          ← dashboard_server.py
  │
  │  用户交互（POST 持久化）:
  │  ├─ POST /api/risk-tags   → 写 risk_tags.json
  │  ├─ POST /api/opp-tags    → 写 opp_tags.json
  │  ├─ POST /api/monitor     → 写 monitor.json
  │  └─ POST /api/index-state → 写 index_state.json
  │
dashboard_server.py（端口 8977）
  │
  └─ 静态文件服务：dashboard.html, trend_view.html 等
```
