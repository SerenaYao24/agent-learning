# 股票趋势分析工具 — 使用方法

## 基本用法

```bash
python stock_trend_analysis.py -i <输入文件.md>
```

## 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--input` | `-i` | **必填**，输入 Markdown 文件路径（股票名称列表） |
| `--output` | `-o` | 输出文件路径，默认按日期自动命名 |
| `--refresh` | | 强制全量刷新，不使用缓存（重新调 API 拉取全量数据） |
| `--multi` | | 仅生成多日趋势汇总报告，跳过单日分析 |
| `--force-gen` | | 使用已有缓存数据，强制重新生成单日 + 多日报告（不调 API） |

## 运行模式详解

### 1. 默认模式（正常分析）

有新数据时自动拉取 → 生成单日报告 → 有 API 调用则自动跟跑多日报告；无新数据则全部走缓存，跳过多日报告。

```bash
python stock_trend_analysis.py -i interest_stock.md
```

### 2. 全量刷新模式

忽略缓存，重新从 API 拉取所有股票数据。

```bash
python stock_trend_analysis.py -i interest_stock.md --refresh
```

### 3. 强制生成报告模式

**不调用 API**，直接用现有缓存数据强制输出单日 + 多日报告。适用于：
- 缓存数据正确，但报告文件被删除/损坏需要重新生成
- 需要用相同数据重新生成报告验证修复效果

```bash
python stock_trend_analysis.py -i interest_stock.md --force-gen
```

### 4. 仅多日报告模式

跳过单日分析，直接强制生成多日趋势汇总报告。

```bash
python stock_trend_analysis.py -i interest_stock.md --multi
```

### 5. 指定输出文件

```bash
python stock_trend_analysis.py -i test.md -o ./test_res.md
```

## 各模式行为对比

| 模式 | 是否调 API | 单日报告 | 多日报告 | 适用场景 |
|------|:----------:|:--------:|:--------:|----------|
| 默认 | 按需增量 | 生成 | 仅有新数据时 | 日常运行 |
| `--refresh` | 全量刷新 | 生成 | 有新数据时 | 缓存过期/需重拉 |
| `--force-gen` | 不调用（走缓存） | **强制生成** | **强制生成** | 重生成报告 |
| `--multi` | 不调用 | 跳过 | **强制生成** | 只看多日汇总 |

## 输出文件位置

报告统一输出到 iCloud 文稿目录下的「股票分析结果」文件夹：

- **每日汇总报告：** `每日分析/stock_trend_report_YYYY-MM-DD.md` — 题材分析表 + 评级统计（轻量概览）
- **每日明细报告：** `每日分析/stock_detail_YYYY-MM-DD.md` — 标的汇总表 + 各标的分析明细 + 评级统计
- **多日分析：** `多日分析/multi_day_trend_YYYY-MM-DD.md`
- **未找到的股票：** `not_found_stocks.txt`

## 输入文件格式

支持按 `## 板块名` 分组的 Markdown 格式：

```markdown
# 我的自选股

## 光纤板块
利通电子
长飞光纤
中天科技

## CPO板块
光迅科技
东山精密
```

## 分析方法说明

### 核心逻辑

1. 收集标的近 10 个交易日的每日涨跌幅
2. 以 5 日为滑动窗口，统计连续 5 日累计涨跌幅（复利计算）
3. 近 10 日数据可形成 6 个滑动窗口
4. 综合评分 = 趋势斜率(30%) + 累计涨幅(30%) + 量价配合(20%) + 启动顺序(20%)

### 关键指标

| 指标 | 说明 |
|------|------|
| 滑动窗口 | 以 5 日为窗口，近 10 日数据可形成 6 个窗口，窗口6 = 最近 5 日累计涨跌幅（复利） |
| 趋势斜率 | 6 个滑动窗口的线性回归斜率，正值表示涨幅扩大 |
| 相对强弱 | 近 5 日累计涨幅与板块平均的差值，正值强于板块 |
| 量价配合 | 上涨时放量、下跌时缩量为佳（-2 到 +2 分） |
| 综合评分 | 0-100 分，分数越高越强势 |

### 告警规则

| 告警类型 | 规则说明 |
|---------|---------|
| 🔴 红灯 | 最后一个窗口（最近 5 日）涨跌幅低于 3%，注意回调风险 |
| 🟢 绿灯 | 涨幅呈扩大趋势，标的启动迹象出现 |
| 🔴 红灯 | 涨幅呈缩小/跌幅扩大趋势，标的走弱迹象出现 |

### 题材分析表说明

汇总报告中的题材分析表按当日标的**平均涨幅降序排列**：

| 列名 | 含义 |
|------|------|
| 题材名称 | 输入文件中 `##` 定义的分组/板块名 |
| 平均涨幅 | 该题材内所有标的当日涨跌幅均值 |
| 标的数 | 该题材有效分析的标的数量 |
| 涨超 5% 数 / 占比 | 当日涨幅 ≥ 5% 的标的数及占比 |
| 最大涨幅标的 | 题材内涨幅最大的标的名称及具体数值 |

## 评级体系

| 评级 | 含义 | 判断条件 |
|------|------|----------|
| 🟢 强势 | 涨且加速 | 5日累计 ≥ 3% 且斜率 > 0 |
| 🟡 冲高回落 | 涨势减弱 | 5日累计 ≥ 3% 但斜率 ≤ 0 |
| 🟠 弱势回调 | 涨幅不足且走弱 | 0 < 5日累计 < 3% 且斜率 < 0 |
| ⭐ 企稳复苏 | 跌幅收窄趋稳 | 5日累计 < 0 但斜率 ≥ 0 |
| 🔴 弱势下跌 | 跌且加速 | 其他情况 |

## 数据缓存

- 缓存文件：`.stock_cache/stock_data.json`
- 代码映射：`.stock_cache/stock_code_map.json`
- 缓存保留最近 30 天
- 支持增量更新：每次运行只拉取缺失的交易日数据

## 走势图可视化 (`generate_trend_page.py`)

从缓存数据生成 K 线 + 成交额 HTML 页面，浏览器直接打开。

### 前置条件

缓存中需要有 OHLCV 数据（open/close/high/low/amount）。如果是首次使用或旧缓存没有这些字段，需先跑一次全量刷新：

```bash
python stock_trend_analysis.py -i interest_stock.md --refresh
```

### 两种模式

#### A. 文件模式 — 指定标的列表文件

展示文件中所有标的的走势图：

```bash
# 默认读 interest_stock.md，展示近 20 日
python generate_trend_page.py

# 指定文件
python generate_trend_page.py -i 我的自选.md

# 指定天数和输出
python generate_trend_page.py -i 我的自选.md --days 30 -o fiber_view.html
```

#### B. 题材模式 — 输入题材名

从 `interest_stock.md` 中找到该题材的所有标的，结合分析报告显示判定结果（进攻/防守）和板块概览：

```bash
python generate_trend_page.py --sector 光通信
python generate_trend_page.py --sector CPO --days 30 -o cpo_view.html
```

题材模式额外功能：
- 页面顶部显示板块概览卡片（板块状态、近5日涨幅、强势占比等）
- 每个标的卡片标注判定结果（启动/强势/企稳复苏 = 进攻；冲高回落/转跌/震荡/弱势下跌 = 防守）
- 进攻票排在前面，防守票排在后面
- 自动校验报告日期：如果最新报告数据滞后过多会报错退出（周六日接受周五数据）

### 参数说明

| 参数 | 简写 | 说明 |
|------|------|------|
| `--input` | `-i` | 标的列表文件（文件模式，默认 `interest_stock.md`） |
| `--sector` | | 题材名称（题材模式，如：光通信、CPO、PCB） |
| `--days` | | 展示近 N 个交易日（默认 20） |
| `--output` | `-o` | 输出 HTML 文件路径（默认 `trend_view.html`） |

### 页面说明

- 4 列卡片平铺，每个卡片 = 1 只标的
- K 线图 + 成交额柱状图
- 深色主题，红涨绿跌
- 鼠标悬停 tooltip 显示：开/收（涨跌额）/高/低/成交额
- 卡片最大宽度 300px
