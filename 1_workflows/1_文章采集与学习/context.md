# 文章采集与学习 - Context

> 工作流层级：workflows / 文章采集与学习
> 本工作流定义：从微信公众号获取文章的通用技术流程
> 创建时间：2026年5月17日

---

## 适用场景

将微信公众号文章内容（文字 + 图片）获取到本地并进行结构化整理。

---

## 技术工具

| 工具 | 用途 | 优先级 |
|------|------|--------|
| `web_fetch` | 快速获取文字、验证链接有效性 | 优先使用 |
| `playwright-cli` | 浏览器自动化，获取图片 URL 和完整 DOM | 第二步 |
| `curl` | 下载图片到本地 | 配合 playwright |

---

## 通用步骤

1. **web_fetch** — 验证链接 + 获取文字内容
2. **playwright-cli open** — 打开文章页面
3. **playwright-cli run-code** — 执行 JS 提取图片 URL（同时检查 `src` 和 `data-src`）
   - 图片扩展名根据 URL 中 `wx_fmt` 参数确定（png/jpg/gif/webp）
4. **curl** — 下载图片到本地
5. **生成 文章内容.md** — 文章标题 + 正文 + 图片插入 + 免责声明
6. **playwright-cli close** — 关闭浏览器

---

## 关键注意点

- 标题以页面元素 `#activity-name` 为准，不以 web_fetch 摘要为准
- 注意 `data-src` 懒加载属性，不要只取 `src`
- 封面图不获取、不插入
- 文章内容.md 只保留文章内容和图片（给人看），技术说明放外层 context
- 每获取一篇立即建目录，不批量等待

---

## 失败模式

| 模式 | 处置 |
|------|------|
| 链接失效（404/超时） | 中断，提示用户 |
| 图片下载失败（403/空文件） | 用页面截图替代，文章中标注 |
| 需要登录才能查看 | 中断，提示用户 |
