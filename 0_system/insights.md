# 系统 Insight

## 报 bug 时给出具体数值矛盾，AI 才能一次定位根因

**场景**：排查 ECharts tooltip 开盘价显示错误。

**现象**：tooltip 里开盘价值不对，反复改都没有改到根因。

**根因**：ECharts 在 tooltip 回调 `params.data` 中返回的结构是 `[dataIndex, open, close, low, high]`，比传给 series 的 `kdata` 多了一个 offset=0 的 index，导致取值的下标整体偏移了 1。AI 多次只看代码不改，是因为它在 Python 端验证过原始数据是对的，形成"数据没问题"的定势。

**教训**：
- 说"不对" → AI 只会反复检查同一个地方（它已经验证过的缓存数据），不会怀疑数据流中间环节
- 说"预期值 X，实际值 Y，两者差在哪" → AI 会对比两个值，立刻定位偏移
- **报 bug 时给出一个具体数值矛盾，AI 大概率一次改对。**

## git 分支名禁止中文

GitHub API 不支持中文分支名（HTTP 400）。任何时候创建/重命名分支，只能用英文、数字、连字符。不用验证、不用问、不用犹豫。
